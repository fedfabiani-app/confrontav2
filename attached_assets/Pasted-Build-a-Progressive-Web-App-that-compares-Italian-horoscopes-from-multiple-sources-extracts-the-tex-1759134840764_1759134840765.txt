Stack: React (frontend PWA), Node.js/Express (backend), MySQL (database), OpenAI API for summaries, category ratings, and tone classification. Fetch pages via HTTP scraping (fetch/axios + cheerio); headless browser only if strictly necessary.

Two workers (TypeScript)

Create two dedicated workers under /server/workers and orchestrate them via a simple in-process job queue:
/server/workers/scraper.ts
Responsibility: build URL from base_url + url_pattern, fetch HTML, extract and clean the horoscope text for a given sign/date/source.
Input type: { sourceId, sourceName, domain, baseUrl, urlPattern, signSlugIt, dateISO, weekdayItNoAccent, gazzettaDatePath, userAgent }
Output type: { sourceId, signSlugIt, dateISO, original_url, scraped_at, extracted_text }
/server/workers/openai.ts
Responsibility: given extracted_text (+metadata), call OpenAI to produce summary (<=300 chars, IT), ratings (relazioni, lavoro, benessere: 1–5), and tone (“positive” | “neutral” | “negative”).
Input type: { sourceId, sourceName, signSlugIt, dateISO, extracted_text }
Output type: { summary, ratings: { relazioni, lavoro, benessere }, tone: "positive"|"neutral"|"negative" }
Orchestration:
Implement /server/jobs/index.ts with two queues (e.g., using p-queue):
scrapeQueue: concurrency ~3, per-domain backoff (e.g., 1–2s), retries with exponential backoff.
nlpQueue: concurrency ~2, global rate limit for OpenAI calls, retries on 429/5xx.
Flow: refresh endpoint enqueues one scrape job per (source, sign, date). On success, enqueue the corresponding NLP job. After NLP completes, persist to DB with upsert.
Provide minimal job status logging; optionally expose GET /api/refresh/status/:jobId for progress (OK to omit if time-constrained).
Implementation details:
Workers can be simple TypeScript modules consumed by the queues (no need for worker_threads unless desired).
Ensure strong typing of inputs/outputs and centralize validation.

Placeholders:
{sign}: Italian slug, lowercase, no accents: ariete, toro, gemelli, cancro, leone, vergine, bilancia, scorpione, sagittario, capricorno, acquario, pesci. Provide IT↔EN mapping in /shared if needed.
{dd}/{day}: two-digit day (01–31).
{mm}/{month}: two-digit month (01–12).
{yyyy}/{year}: four-digit year.
{weekday}: Italian lowercase, no accents: lunedi, martedi, mercoledi, giovedi, venerdi, sabato, domenica.
{date}: for Gazzetta use YYYY/MM/DD.
