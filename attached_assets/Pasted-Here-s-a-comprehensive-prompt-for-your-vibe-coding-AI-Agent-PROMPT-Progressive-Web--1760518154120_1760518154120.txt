## **PROMPT: Progressive Web App - Automatic Database Cleanup System**

### **Objective**
Implement an automated database maintenance system for a Progressive Web App that cleans up horoscope data every 31 days.

### **Requirements**

**Database Tables to Clean:**
- `horoscope_data`
- `weekly_horoscope_data`

**Cleanup Operations (every 31 days):**
1. **DELETE** all existing records from both tables
2. **RESET** the auto-increment `id` column to start from 1
3. **LOG** the cleanup operation with timestamp
4. **VERIFY** operation success

### **Technical Specifications**

**Cleanup Frequency:** Every 31 days (744 hours)

**Implementation Options:**
1. **Cron Job** (Linux/Unix servers)
2. **Database Scheduled Events** (MySQL/PostgreSQL)
3. **Application-level Scheduler** (Node.js with node-cron)
4. **Cloud Functions** (Serverless approach)

### **Code Requirements**

**SQL Operations Needed:**
```sql
-- Clean tables
DELETE FROM horoscope_data;
DELETE FROM weekly_horoscope_data;

-- Reset auto-increment
ALTER TABLE horoscope_data AUTO_INCREMENT = 1;
ALTER TABLE weekly_horoscope_data AUTO_INCREMENT = 1;
```

**Implementation Features:**
- ✅ **Error Handling**: Catch and log any database errors
- ✅ **Backup Option**: Optional backup before deletion
- ✅ **Rollback Mechanism**: Ability to restore if needed
- ✅ **Logging System**: Track all cleanup operations
- ✅ **Health Checks**: Verify system status after cleanup
- ✅ **Configuration**: Easy to modify cleanup interval

### **Suggested Architecture**

**Option 1: Node.js with node-cron**
